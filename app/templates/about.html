About {{ app_name }}

Local AI video dubbing for supported Indian languages.

What Bhasha Mitra does

{{ app_name }} takes a video, understands its speech, translates the content into a target language, synthesizes natural-sounding speech in that language, and re-combines it with the original video to produce a dubbed video - entirely on your local machine's CPU, with no data ever leaving your computer.

The pipeline

  1. Speech recognition - the configured Faster-Whisper or IndicConformer model transcribes the source audio.
  2. Translation - the configured route translates English → Indic, Indic → Indic, or Indic → English.
  3. Speech synthesis - the active Piper or Parler model generates speech in the target language for each segment.
  4. Re-assembly - the dubbed speech is time-aligned to the original segments and muxed back into the video.

Configurable AI models

AI model catalogs are stored outside the application in config/models.json. Each catalog supports multiple configured models, enabled or disabled entries, and an externally selected active model.

  • ASR - separate English and Indic model catalogs.
  • Translation - independent catalogs for English → Indic, Indic → Indic, and Indic → English.
  • TTS - a model catalog for Piper and Parler engines, preserving Piper voice mappings.

Selecting another model supported by an existing engine requires only an external JSON change and application restart; rebuilding the EXE is not required. Model assets remain under the external models/ directory.

Translation direction & language support

{{ app_name }} uses dedicated configured translation models for each supported route:

  • Source language = target language → no translation needed.
  • Source is English → the English-to-Indic catalog translates directly to the target Indic language.
  • Source and target are Indic → the Indic-to-Indic catalog translates directly.
  • Target is English → the Indic-to-English catalog translates directly.

Text translation can automatically detect a source language when no manual source override is supplied. Low-confidence or unsupported detection is rejected clearly.
